# Tekshiruv hisoboti — ktp26-u-26 (batch w3)

| ko‘rsatkich | soni |
|---|---|
| yangi/o‘zgargan bullet | 30 |
| yangi/almashtirilgan diagramma | 14 |
| yangi mcq | 0 (jami mcq 20, hammasi ko‘rib chiqildi) |
| tuzatilgan element | 1 |
| o‘chirilgan | 0 |
| uncertain qilingan | 0 |
| validator (--strict) | 0 xato |

Usul: har element ko‘rsatilgan bet (±1) matni bilan avtomatik solishtirildi (raqam, `N-modda`, so‘z o‘zaklari), shubhalilar va barcha yangi mcq qo‘lda manba matni bilan o‘qib chiqildi; qisqartirilgan bulletlar eski nusxa bilan juftlab ko‘rildi (ma’no yo‘qolishi).

## Tuzatishlar
- S27b4: matn: "Siqilishda fasciotomiya yopiq jarohatni ochiqqa aylantirib, infeksiya xavfini oshiradi. Qon aylanishi pasaymasa, konservativ yo‘l tavsiya etilgan." -> "Fasciotomiya yopiq jarohatni ochiqqa aylantirib, infeksiyani oshiradi. Ochiq jarohat yoki qon aylanishi pasayishi bo‘lmasa, konservativ yo‘l tavsiya etilgan." (qisqartirishda shart «ochiq jarohat yoki qon aylanishi pasaysa» tushib qolgan edi; Guo et al.)

## Qolgan shubhalar (ilmiy muharrirga)
- Usuda (PMC) va Guo matnlari bilan raqamlar, mcq (20 ta) va yangi bulletlar qo‘lda solishtirildi; S39b2 da «CO bilan boyitilgan eritrotsitlar» elementi qisqartirishda tushgan.
- Eski (o‘zgarmagan) bulletlar uchun avtomatik tekshiruvda ba'zi OCR/so‘z shakli farqlari belgilandi, ammo ular bu batch doirasida o‘zgartirilmadi.
