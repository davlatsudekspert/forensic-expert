## РУССКИЙ

### Краткое описание (76 символов)

Справочник для судебных экспертов: вещества, методы, реактивы, источники
```

### Полное описание

```
FORENSIC EXPERT — профессиональный справочник и учебный инструмент для
специалистов судебной экспертизы. Собирает в одном месте то, что нужно в
повседневной работе по судебной химии, судебной медицине и судебной
биологии, — и каждое сведение приводится с источником и точной страницей.

ЧТО ВНУТРИ

• Библиотека веществ — данные для идентификации, метаболиты, виды
  образцов, концентрации, приведённые в источниках.
• Методы обнаружения — цветные (капельные) пробы, тонкослойная
  хроматография, микрокристаллические пробы, УФ-спектр, фотометрия,
  иммуноанализ и подтверждающие инструментальные методы. Под каждым
  методом указан источник и его точное место.
• Реактивы — порядок приготовления, хранение и примечания по безопасности.
  Вещества с непроверенными данными об опасности отмечаются отдельно.
• Методические карты — судебная биология (кровь, сперма, слюна, волосы,
  работа с вещественными доказательствами), токсикология, CO/COHb, ПМИ.
• Калькуляторы — молярность, массовая концентрация, проценты, единицы,
  статистика, регрессия, LOD/LOQ.
• Библиотека научных источников — статьи, руководства, стандарты. Для
  каждого источника показано, на каком уровне он проверен.
• Подготовка к допросу в суде — точные, основанные на источниках ответы
  об ограничениях метода.
• Режим тестирования — проверка знаний; к каждому вопросу объяснение и
  источник.
• ИИ-помощник — ответы опираются на источники приложения и выдаются со
  списком источников. Текст ИИ помечается отдельно.

НА ТРЁХ ЯЗЫКАХ

Всё приложение — и интерфейс, и научное содержание — на узбекском,
русском и английском. Сначала вы видите объяснение на своём языке;
исходный текст источника открывается отдельно. Автор, оригинальное
название, DOI и номер страницы никогда не переводятся.

ПРИНЦИПЫ ДОБРОСОВЕСТНОСТИ

• Приложение НЕ ЗАМЕНЯЕТ ЗАКЛЮЧЕНИЕ ЭКСПЕРТА. Это справочный и учебный
  инструмент; любое заключение эксперт делает под свою ответственность.
• Статус каждого сведения показан открыто: установлен ли источник,
  проверено ли научное основание, прошло ли экспертное рецензирование
  или требуется дополнительная проверка.
• Непроверенный машинный перевод помечается как таковой.
• Вещества упоминаются только в контексте ОБНАРУЖЕНИЯ и экспертизы. В
  приложении нет инструкций по изготовлению или употреблению.
• Без рекламы. Для профессиональных пользователей старше 18 лет.

КОНФИДЕНЦИАЛЬНОСТЬ

Вход по одноразовому коду на электронную почту. Можно работать и без
учётной записи. Загруженные документы о квалификации хранятся
конфиденциально и доступны только уполномоченному проверяющему. Учётную
запись можно полностью удалить из самого приложения.
```

## ENGLISH

### Short description (74 characters)

```
Sourced reference for forensic experts: substances, methods, reagents
```

### Full description

```
FORENSIC EXPERT is a professional reference and study tool for forensic
practitioners. It brings together what forensic chemistry, forensic
medicine and forensic biology work needs day to day — and every statement
carries its source and the exact page.

WHAT IS INSIDE

• Substance library — identification data, metabolites, specimen types and
  the concentrations reported in the literature.
• Detection methods — colour (spot) tests, thin-layer chromatography,
  microcrystalline tests, UV spectra, photometry, immunoassay and
  confirmatory instrumental methods. Each entry names its source and the
  exact place in it.
• Reagents — preparation, storage and safety notes. Substances whose
  hazard data could not be verified are marked as such.
• Guideline cards — forensic biology (blood, semen, saliva, hair, evidence
  handling), toxicology, CO/COHb, post-mortem interval and more.
• Calculators — molarity, mass concentration, percentages, units,
  statistics, regression, LOD/LOQ.
• Scientific source library — articles, guidelines and standards, each
  showing how far it was verified.
• Court questioning preparation — precise, source-backed answers about the
  limitations of a method.
• Study mode — test yourself; every question carries an explanation and a
  source.
• AI assistant — answers are grounded in the app's own sources and come
  with the source list. AI text is marked separately.

IN THREE LANGUAGES

The whole app — interface and scientific content alike — is in Uzbek,
Russian and English. You see the explanation in your own language first;
the original source text opens separately. Author, original title, DOI and
page number are never translated.

HONESTY RULES

• The app DOES NOT REPLACE AN EXPERT OPINION. It is a reference and study
  tool; every conclusion remains the practitioner's own responsibility.
• The status of each statement is shown openly: whether its source is
  established, whether its scientific basis was checked, whether it passed
  expert review, or whether further verification is required.
• Unreviewed machine translation is labelled as such.
• Substances are covered only in the context of DETECTION and forensic
  examination. The app contains no preparation or consumption instructions.
• No advertising. For professional users aged 18 and over.

PRIVACY

Sign-in uses a one-time code sent to your email. The app also works without
an account. Uploaded qualification documents are stored confidentially and
seen only by an authorised reviewer. An account can be deleted entirely
from within the app.
```

• Forensic biology guideline cards: blood, semen, saliva, hair, evidence

• Automatic claim-to-source integrity checking
• Reagents section with safety notes
```
