**Подзаголовок:** Справочник судебной экспертизы

**Краткое описание:** Офлайн-справочник судебной экспертизы с источниками, статусом проверки и правовым контекстом.

**Полное описание:**
FORENSIC EXPERT — офлайн-справочник для студентов и специалистов в судебной медицине, токсикологии, генетике и смежных дисциплинах.

- Каждое научное утверждение сопровождается источником и статусом проверки. Материалы, ещё не проверенные квалифицированным экспертом, явно помечены.
- Методы отмечены по типу доказательности (международный стандарт, руководство, опубликованный метод, учебное резюме).
- Правовой раздел для небольшого числа пилотных юрисдикций с официальными источниками; для остальных стран — «Нет проверенного контента», а не чужое законодательство.
- Калькуляторы с явными формулами и ограничениями.
- Полностью офлайн; без отслеживания и рекламы.

Важно: FORENSIC EXPERT — учебный справочник. Он не заменяет лабораторные СОП, аккредитованные методики, юридическую консультацию или заключение квалифицированного эксперта.

**Ключевые слова:** судебная медицина, токсикология, вскрытие, ДНК, доказательства
**Конфиденциальность:** отслеживания нет. Необязательный аккаунт собирает только эл. почту; история покупок используется для проверки подписок.
**Цена:** бесплатный уровень; необязательные автопродлеваемые подписки Student Pro и Professional Pro (месяц / год) — цены только из магазина. Аккаунт необязателен.
