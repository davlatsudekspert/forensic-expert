# Maxfiylik siyosati URL'i — yordamchi uchun prompt (2-qadam)

Quyidagi matnni yordamchiga bering **va `privacy.html` faylini ham biriktiring**.

---

Men Google Play Console'da **FORENSIC EXPERT** ilovasini chiqarmoqdaman.
Hozir **2-qadam — maxfiylik siyosati URL'i** ustida ishlayapman. Bu maydon
majburiy: usiz release boshlanmaydi.

Menda **tayyor HTML fayl bor** — uni shu xabarga biriktirdim. Ichida maxfiylik
siyosati uch tilda (o'zbek, rus, ingliz). Matnni o'zgartirish kerak emas, uni
shunchaki ochiq manzilga joylashtirish kerak.

Men texnik odam emasman — har qadamni **o'zbek tilida**, sodda tushuntir,
bir vaqtda bitta qadam ber. Skrinshot yuborsam, nima bosishim kerakligini ayt.

## Nima qilish kerak

GitHub Pages orqali bepul ochiq sahifa yarataylik. Mening GitHub hisobim:
**davlatsudekspert**.

1. **Yangi ochiq repo.** https://github.com/new
   - Repository name: `forensic-expert-legal`
   - **Public** (ochiq) — bu muhim, chunki Google tekshiruvchisi hisobsiz
     ocha olishi kerak
   - «Add a README file» belgilansin
   - Create repository

2. **Faylni yuklash.** Repo ichida: Add file → Upload files.
   Biriktirilgan `privacy.html` faylini yuklaymiz, lekin nomi **`index.html`**
   bo'lishi kerak. Faylni yuklashdan oldin nomini o'zgartirishim kerakmi yoki
   GitHub'da o'zgartirsa bo'ladimi — ayt. Keyin Commit changes.

3. **Pages'ni yoqish.** Settings → Pages:
   - Source: `Deploy from a branch`
   - Branch: `main`, papka `/ (root)`
   - Save

4. **Manzilni tekshirish.** 1–2 daqiqadan keyin quyidagi havola ochilishi kerak:
   `https://davlatsudekspert.github.io/forensic-expert-legal/`
   Agar 404 chiqsa, nima qilishimni ayt (odatda bir-ikki daqiqa kutish kerak).
   Havolani **yashirin oynada** (incognito) ham ochib ko'raylik — Google
   tekshiruvchisi hisobsiz ochadi, shuning uchun shunday tekshirish kerak.

5. **Play Console'ga kiritish.** Shu havolani Privacy policy maydoniga
   yozamiz. Play Console'da aniq qayerda ekanini ayt (menyu yo'li bilan).
   Sahifa uchta tilda — Play'ga bitta havola yetadimi yoki har til uchun
   alohida kerakmi, shuni ham ayt.

## Muhim

- Repo **ochiq** bo'lishi shart, lekin ichida faqat shu bitta sahifa bo'ladi —
  ilova kodi emas. Ilova kodi boshqa, yopiq repoda qoladi.
- Fayl mazmunini o'zgartirma. Agar biror joyi xato ko'rinsa, menga ayt, men
  tuzattiraman.
- Agar GitHub'da biror qadam ishlamasa (masalan Pages yoqilmasa), muqobil
  yo'lni ham ayt — masalan Google Sites.

## Birinchi javobing

1-qadamdan boshla: repo yaratish. Qaysi tugmani bosishimni aniq ayt.
