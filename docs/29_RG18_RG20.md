## RG-18 — `packages/fe_purchase_verification` (faqat server)

Mobil ilova bu paketga bog‘lanmaydi; sirlar faqat server muhitida.

| Qism | Fayl | Vazifa |

**Qoidalar (fail closed):** ruxsat etilgan mahsulot; xarid ma’lumoti faqat store’dan; bundle ID / package name mosligi; production’da sandbox rad; refund/revoke/sotib olinmagan — huquq yo‘q; **replay** — bitta xarid faqat bitta akkauntga (atomik noyob kalit); **idempotentlik** — bir xil kalit, bir xil natija; store javob bermasa — huquq berilmaydi va natija keshlanmaydi; Google xaridi acknowledge qilinadi; Apple V2 `REFUND`/`REVOKE` va Google voided purchase → huquq bekor. Mock komponentlar production rejimida server ishga tushishini to‘xtatadi.

**Testlar:** 10 ta (`test/purchase_verification_test.dart`) — barchasi mock bilan. **Haqiqiy Apple/Google tekshiruvi bajarilmagan.**

### Qolgan tashqi sozlash (inson / hisob egasi)

1. Backend joylashtirish (auth bilan akkaunt ID; tranzaksion DB, `(platform, original_transaction_id)` noyob indeksi).
2. **Apple:** App Store Connect’da In-App Purchase kaliti (Issuer ID, Key ID, `.p8`) — server sirlarida; App Store Server API mijozi; JWS x5c zanjirini Apple Root CA G3 ga qadar tekshirish; App Store Server Notifications V2 URL.
3. **Google:** Play Console’da service account (`androidpublisher`), Developer API mijozi; Real-time Developer Notifications (Pub/Sub topic + OIDC autentifikatsiyali push); Voided Purchases API.
4. Store’da mahsulotlarni yaratish (RG-16) va sandbox testlari.
5. Ilova: `EntitlementVerification.serverVerified` faqat backend javobidan.
