Demo account (teacher role) is provided above. Sign in: Profile → Sign in →
e-mail and password.

Most of the app (substance library, methods, reagents, guideline cards,
calculators, search, study mode, AI assistant) opens without signing in.

Teacher features (only for accounts with the teacher role):
1. Lessons: Profile → Teacher panel → Lessons. Search a topic, open a
   lecture, swipe/tap through slides; "Projector" shows the slide full-screen
   in landscape for a classroom screen. Slides are view-only (no download,
   no sharing). After the last slide the teacher can start a quiz on the
   same topic. Lecture slides are currently in Uzbek (marked "translation
   pending" in other languages).
2. Class quiz: Teacher panel → Run a test → choose a topic → Create. A
   6-digit code and QR appear on the big screen. Students join from their own
   phones (Join a class → enter code) and answer timed multiple-choice
   questions; the teacher sees the answer count, the correct answer after
   time is up, and a leaderboard. To try it alone, join from a second device
   with any other account.
3. Groups and topic tests: Teacher panel → Groups → create a group →
   "Give topic test" (or "Combined test"): choose topics, number of
   questions, time limit and how long the test stays open. One QR/code for
   the whole group; signed-in students join and solve at their own pace;
   each student may get a different question set; the server scores; correct
   answers open after the deadline or when the teacher closes the test.

All content is educational reference material for forensic medicine and
forensic toxicological chemistry, written from university textbooks with
the exact source and page shown on every slide and question. Controlled
substances appear only as analytical identification data (colour tests,
chromatography, spectra). No ads, no tracking, no purchases — everything is
free. Account deletion: Profile → Account → Delete account.
